# alpoker-lab

ブラウザで遊べる、CPU相手の 5-Max（1卓5人）ポーカートーナメント（MTT）です。

## 遊び方
`index.html` をブラウザで開くだけで遊べます。インストールやサーバーは不要です。

## ゲームの概要
- 40人参加（あなた＋CPU39人）、8卓でスタート
- 開始スタック 10000点、ブラインドは13段階で時間とともに上昇（5分 / 2分 / 1分から選択）
- リエントリーは1回まで（Lv1〜2のみ）
- 上位20%が入賞（ITM）
- CPUは6タイプ：タイト・ルースアグレ・コーラー・マニアック・バランス・ICM意識
- 通常より強いネームドCPU：**Croque** / **Hubris** / **Kaina**
- 戦績はブラウザに保存されます（別のブラウザ・端末には引き継がれません）

## ファイル構成
```
index.html                          ゲーム本体（HTML・CSS・JavaScriptがすべてこの1ファイル）
README.md                           このファイル
CLAUDE.md                           Claudeに作業してもらうときのルール
.github/pull_request_template.md    PRを作るときの記入テンプレート
```

## 開発の進め方
1. `main` に直接アップロード・編集はしない
2. ブランチを作って変更し、PR（プルリクエスト）を出す
3. もう一人が中身を見て、問題なければマージする

細かいルールは [CLAUDE.md](CLAUDE.md) にまとめています。
